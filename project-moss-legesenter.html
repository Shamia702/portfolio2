Client Project · Medical Clinic

Moss Legesenter

View live site ↗

A responsive website created for a real medical clinic in Moss, Norway. The project included frontend development, Netlify deployment, custom domain setup, HTTPS, Google Search Console, and basic SEO configuration.

The brief

Create a professional, responsive website for Moss Legesenter, a medical clinic in Norway, and prepare it for launch on the clinic's own domain.

Development and launch

My work covered frontend development and the setup needed to publish the website. I deployed the site on Netlify, connected the custom domain, and configured HTTPS. I also set up Google Search Console and basic SEO configuration.

Project scope

  • Responsive frontend: a layout for mobile, tablet, and desktop screens.
  • Deployment: Netlify hosting and custom domain setup.
  • HTTPS: secure access through the clinic's domain.
  • Search setup: Google Search Console and basic SEO.
